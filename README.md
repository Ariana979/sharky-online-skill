# sharky-online — Claude Code skill

Build a free-form HTML game in Claude Code and publish it to
[sharky.gg](https://sharky.gg) with real platform multiplayer — accounts,
rooms, a server-ordered sync bus. This repo IS the skill, ready to install;
everything it does is documented in [SKILL.md](SKILL.md).

## Install

```bash
git clone <this-repo-url> ~/.claude/skills/sharky-online
```

(or copy this directory into a project's `.claude/skills/sharky-online/`)

Then just ask Claude Code: “用 sharky online 做一个…” / “use the
sharky-online skill to …”.
